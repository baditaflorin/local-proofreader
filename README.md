# Local Proofreader

Live site: https://baditaflorin.github.io/local-proofreader/

Repository: https://github.com/baditaflorin/local-proofreader

Local Proofreader is a local-first grammar, spelling, and style assistant for people who want Grammarly-like feedback without sending drafts to a server.

## Quickstart

```sh
npm install
make install-hooks
make build
make pages-preview
```

## Status

This repository is built for GitHub Pages from `main` branch `/docs`. The app shows the published version and commit in the UI via `public/version.json`.

# Contributing

Thanks for helping improve Local Proofreader.

1. Run `npm install`.
2. Run `make install-hooks`.
3. Make focused changes with tests.
4. Run `make lint`, `make test`, `make build`, and `make smoke`.
5. Use Conventional Commits, such as `feat: add passive voice rule`.

Do not commit secrets, private keys, `.env` files, or private draft text.

# Privacy

Local Proofreader is designed so draft text stays in the browser.

What is collected:

- No analytics are collected in v1.
- No draft text is sent to a hosted API.
- No account, email, or payment data is collected by the app.

What is stored locally:

- Draft snapshots if autosave is enabled.
- Accepted local dictionary words.
- Recent local analysis counts and timings.

Support and repository links:

- https://github.com/baditaflorin/local-proofreader
- https://www.paypal.com/paypalme/florinbadita

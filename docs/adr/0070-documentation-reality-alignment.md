# 0070 Documentation Reality Alignment

- Status: accepted

## Context

README and extension docs are already close, but a few claims are broader than the shipped surface.

## Decision

Every user-visible claim must map to a real control, persisted behavior, or test-backed path. Where the shipped behavior is narrower, docs will become more explicit instead of more promotional.

## Consequences

The repo becomes easier to trust and easier to maintain.

## Alternatives Considered

Keeping aspirational wording was rejected because it weakens the stranger test.
